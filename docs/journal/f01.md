### Öğrenilen (26.3)
- `ModConfig.Type`: `LOCAL / CLIENT / SYNCED / STARTUP` (eski COMMON/SERVER yok).
- Clientbound payload işleyicisi ayrı olayda: `RegisterClientPayloadHandlersEvent#register(type, handler)`; `PayloadRegistrar#playToClient(type, codec)` işleyicisiz.
- Attachment `sync(streamCodec)` + `setData` → istemciye kendiliğinden gider (elle payload gerekmedi). `serialize` `MapCodec` ister.
- Komut izni: `.requires(Commands.hasPermission(Commands.LEVEL_GAMEMASTERS))`.
- `PlayerList#respawn(player, keepAllPlayerData, RemovalReason)` sahte bağlantılı (`EmbeddedChannel`) oyuncuyla GameTest'te çalışıyor → Faz 4 kanat kalıcılığı başsız test edilebilir.
- Sunucu tarafı `Component#getString()` mod lang'ini (en_us) çözüyor.
- `GameTestHelper#makeMockServerPlayerInLevel` yerine gerçek `ServerPlayer` + `setGameMode(SURVIVAL)` yeterli (spike'taki `gameMode()` override'ı gereksizmiş).
- İstemci konsolunda 28 adet `[mvk-warn] VK_ERROR_FEATURE_NOT_PRESENT: Metal does not support disabling primitive restart` — MoltenVK'nin stderr uyarısı; oyun log dosyasına düşmüyor, test geçti. Nedenini araştırmadım.
