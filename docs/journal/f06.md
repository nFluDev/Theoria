### Mimari kararlar (neden)
- **gear.json jar kaynağı, datapack değil:** item/blok kaydı ve vanilla bileşen bağlama datapack'ten önce olur (ADR-003 Karar 2 ile aynı gerekçe). Datapack'teki `tier/*.json` (hasar formülü) ile `gear.json` aynı CSV'den akar; `/theoria test gear` ikisinin aynı sayıyı verdiğini çalışırken doğrular.
- **Renk pişirilmiş (çalışma anı tint'i değil):** docs/03 "tint'li doku varyantları". Vanilla demir şablonundan malzeme rengine rampa (gölge·renk·parlak) ile boyanmış PNG: BlockColor/ItemColor/DYED_COLOR kodu yok, Vitrail/shader paketi için özel yol yok (vanilla render tipleri). Saplar kahverengi kalır; cevherde yalnız vanilla beneklerin taş dokudan farkı boyanır. Yeni malzeme = bir renk.
- **Kazı kapıları etiketle:** `theoria:gate/<idx>` + her alet kademesi için `incorrect_for_*_tool`. Vanilla `needs_*` seviyeleri korunur (üçüncü taraf modlar bozulmaz); tek çatışma kırmızıtaş (vanilla'da demir, bizde bakır) → etiketten `remove`. Vanilla cevher sertliği AT ile (`BlockStateBase.destroySpeed`) ortak kurulumda yazılır.
- **Vanilla override = `ModifyDefaultComponentsEvent`** (NeoForge, mixin'siz): 4 bileşen (dayanıklılık, büyü yeteneği, nitelikler, `Tool` kuralı hızı). Eksik vanilla id yüksek sesle düşer.
- **Netherite süzgeci global loot modifier + etiket** (`theoria:removed_gear`): başka modların tabloları da süzülür; tarif tarafı `neoforge:never`.
- **Sapma — obsidyen/antik enkaz sertliği vanilla kaldı** (docs/05 §7'deki 9,0 formülün körlemesine uygulanmasıydı): Q36.
- **Sapma — deepslate × 1,5 yalnız taş ikizi varsa;** kobalt/mitril/platin yalnız deepslate'te → tablo değeri bloğun kendisinin.
- **Öntanımlı büyüler Faz 7a'ya** (Q34): yalnız nitelik tabanlı özellikler yapıldı. Gerekçe: `ref_epf` + dayanıklılık eğrisi bunları zaten kapsıyor (bütçe iki kez sayılırdı), taşlama taşıyla silinirdi, parlama verirdi; platin "+1 katalizör yuvası"/orikalkum element direnci katalizör şemasına bağlı.
- Zırh parçası dayanıklılığı = göğüslük × 11/16, 1, 15/16, 13/16 **yarım yukarı** (Python `round` bankacı yuvarlaması Java `Math.round` ile farklı çıktı: 112,5 → 112 ≠ 113; test yakaladı).
- Zincir/kaplumbağa/at/denizci/kurt zırhı vanilla bırakıldı (zincir takımı 12 puan ≈ kalay 7 ile bakır 14 arası: tutarlı).
- Depolama blokları: sertlik 5 / direnç 6, kademesine göre `needs_stone/iron/diamond_tool` (denge tablosunda yok).

### Öğrenilen (26.3 API — tahmin değil, kaynak/log)
| Konu | Gerçek |
|---|---|
| Vanilla eşya statını değiştirmek | `ModifyDefaultComponentsEvent` (mod bus) — `HolderLookup.Provider` ile çalışır; default bileşenler kayıt defterleri (datapack dahil) yüklendikten SONRA bağlanır |
| Loot JSON | `"type"` ayırıcı, işlev anahtarı `"modifier"`, koşul `"condition"` (havuz ve giriş düzeyinde tek nesne) |
| Dünya üretimi | yapılandırılmış özellik klasörü artık `worldgen/feature` (`Registries.FEATURE`); cevher hedefinde `"state"` düz kimlik (`{"Name":…}` değil) |
| Tarif kaldırma | `recipe` bir **datapack kayıt defteri**: tarifi `neoforge:never` ile düşürünce ona başvuran **ilerleme** (`advancement/recipes/*/netherite_*_smithing`) "Unbound values in registry recipe" ile açılışı ÇÖKERTİR → ilerleme de aynı koşulla düşürülmeli |
| NeoForge'un vanilla tarif kopyaları | NeoForge bazı vanilla tarifleri kendi sürümüyle gönderiyor (`netherite_upgrade_smithing_template`: `#c:gems/diamond`) ve bizim override'ımızı eziyor (Q39) |
| Etiket `remove` | vanilla `TagFile` `remove` dizisini destekliyor (başka paketin girdisini çıkarmak için) |
| GLM | `data/<ns>/loot_modifiers/<ad>.json`; ayrı kayıt listesi dosyası yok; `neoforge:add_table` + `neoforge:loot_table_id` koşulu |
| Vanilla adlar | `golden_*` / `wooden_*` (gold/wood değil); 26.3'te bakır alet+zırh ve **mızrak** (kinetik silah) var; mızrağın hasarı = `taban + floor(bağıl hız × çarpan)` |
| `Tool` bileşeni | ilk kural `deniesDrops(incorrect tag)`, ikinci `minesAndDrops(mineable, hız)`; yanlış alet hızı aynı kalır, ceza kırma ilerlemesinde (30 ↔ 100) |
| Ekipman nitelikleri | varlığın kendi tick'inde uygulanır (`setItemSlot` hemen değil) → GameTest bekleme ister |
| Ore özelliği | `size 2` damar hiç blok koymayabiliyor (60 denemede 0) → `check_gear` boyut ≥ 3 ister |
| `pngio` | gri/RGB PNG'lerde `tRNS` renk anahtarı yok sayılıyordu (vanilla külçe/alet dokuları böyle: köşeler opak siyah çıkıyordu) → düzeltildi, `check_hud` hâlâ yeşil |
| macOS | `timeout` komutu yok (exit 127); gözetimsiz oyun için Python `subprocess.run(timeout=…)` (bench.py gibi) |
